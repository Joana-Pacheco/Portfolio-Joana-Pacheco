
# 🌐 Portfólio Pessoal – Fundamentos da Programação Web

Projeto desenvolvido para a disciplina **Fundamentos da Programação Web**, com o objetivo de criar um portfólio online aplicando HTML5, CSS3 e JavaScript, com publicação obrigatória em serviço de hospedagem gratuito.

---

## 📌 Objetivo da Atividade

Desenvolver um site de portfólio pessoal (Currículo Online), contendo 4 seções obrigatórias, utilizando:

- ✅ HTML5 (estrutura)
- ✅ CSS3 (estilização – sem uso de frameworks)
- ✅ JavaScript (validação e interação – sem uso de frameworks)
- ✅ Versionamento no GitHub
- ✅ Deploy no GitHub Pages

## 📂 Estrutura do Projeto

O site foi desenvolvido utilizando o modelo de **páginas separadas**, contendo:

- `index.html` → Sobre mim  
- `formacao.html` → Formação  
- `portfolio.html` → Portfólio  
- `contato.html` → Contato  
- `css/style.css` → Estilização do site  
- `script.js` → Validação do formulário  

Todas as páginas possuem um menu fixo de navegação interligando as seções.

--------------

## 🧩 Seções Obrigatórias

### 👩‍💻 Sobre Mim
Apresentação pessoal, informações sobre interesses e objetivos profissionais.

### 🎓 Formação
Informações sobre formação acadêmica, cursos e idiomas.

### 📁 Portfólio
Lista de projetos desenvolvidos durante a formação na área de tecnologia, com links para o GitHub.

### 📩 Contato
Formulário contendo:
- Nome
- E-mail
- Mensagem

Funcionalidades implementadas em JavaScript:
- ✔ Validação de campos obrigatórios
- ✔ Validação de formato de e-mail
- ✔ Simulação de envio com mensagem de confirmação
- ✔ Limpeza automática do formulário após envio
